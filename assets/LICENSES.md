# Asset Licenses and Attributions - Dungeon Reborn

This document details the origins and licenses for all graphical, font, and audio assets included in the **Dungeon Reborn** project.

## 1. Graphics: 0x72 Dungeon Tileset II (v1.3)
- **Creator / Artist:** Robert Norenberg (0x72)
- **Source:** [https://0x72.itch.io/dungeontileset-ii](https://0x72.itch.io/dungeontileset-ii)
- **License:** Creative Commons Zero v1.0 Universal (CC0 1.0 - Public Domain Dedication)
- **Files:** `assets/images/dungeon_tileset.png`
- **Included Sprites:**
  - Playable Knight (idle, run, hit animations)
  - Skeleton Warrior (idle, run animations)
  - Goblin (idle, run animations)
  - Big Demon Boss (idle, run animations)
  - Dungeon floors, walls, corners, banners, doors (closed and open)
  - Items: Swords, potions (health, speed), chests, coins, UI heart containers

## 2. Typography: BitPotionExt Pixel Font
- **Creator:** JoebRogers
- **License:** Creative Commons Zero / SIL Open Font License
- **File:** `assets/fonts/dungeon_font.ttf`
- **Purpose:** Retro pixelated typography for HUD, dialogues, menus, damage text, and game-over screens.

## 3. Audio: Synthesized Retro 8-bit Sound Effects
- **Author:** Dungeon Reborn Project Sound Generator
